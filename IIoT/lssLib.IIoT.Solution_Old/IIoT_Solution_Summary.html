런타임 전환 흐름

// App.xaml.cs — 앱 시작 시
_themeSettings = new ThemeSettingsService();
_themeSettings.LoadAndApply(this);    // %AppData%\IIoT\ui-settings.json 복원
                                           // 파일 없으면 DarkNavy 기본값 적용

// 런타임 즉시 전환 (DynamicResource 전체 자동 갱신)
ThemeManager.Apply(ThemeKind.NeonCyber);

// 페이드 애니메이션 전환 (180ms)
await ThemeTransitionService.ApplyWithTransitionAsync(
    ThemeKind.WarmAmber, rootGrid, Application.Current);

// 단축키 순환 (Ctrl+T / Ctrl+Shift+T)
_themeVm.NextThemeCommand.Execute(null);

4프로그램 간 연결 구조

DeviceManager ──→ config.json ←── FileSystemWatcher ←── Collector (재시작)
DeviceManager ──→ config.json ←── Monitor (알람 임계값 갱신)

Collector ──→ EventBus (TagValueEvent) ──→ Monitor (실시간 수신)
Collector ──→ DataStore (CommandQueue) ──→ SQLite (SDT 압축 후 저장)
Monitor   ──→ gRPC Stream (AnomalyEvent) ──→ Manager
Manager   ──→ gRPC Named Pipe (Start/Stop/HealthCheck) ──→ All Programs

IPC 채널 종류

채널사용처방향
FileSystemWatcher + config.json설정 변경 전파DeviceManager → Collector/Monitor
gRPC Named Pipe프로세스 제어 (Start/Stop)Manager → 전체
lssLib EventBus실시간 TagValue 스트리밍Collector → Monitor
lssLib CommandQueueDB 저장 요청Collector → DataStore
MQTT (MQTTnet)핫 리로드 명령Manager → Collector
SignalR (Web)모니터링 웹 뷰어Monitor → Browser
