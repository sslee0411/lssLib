① DeviceManager
WPF · device.json 쓰기

장비 타입 템플릿 캡처 / 인스턴스화

CSV / Excel 태그 대량 Import
원자적 JSON 저장 → SHA-256 무결성
변경 이력 Audit Log (전/후 스냅샷)
② CollectConfig
WPF · collect.json 쓰기
NodeRed 방식 FlowCanvas 편집기
BufParser 테이블 (BufSchema 필드 정의)
Modbus / Serial / OPC-UA / MQTT 채널 설정
Primary-Backup 이중화 통신 설정
Scale / DeadBand / MathNode 처리 파이프라인
시뮬레이터 노드로 실장비 없이 테스트
런타임 TPS / 에러율 실시간 플로우 뷰
③ Monitor
WPF + ASP.NET · monitor.json 쓰기
AbstractDetector 상속 확장 감지기 프레임워크
SPC 관리도 UCL/LCL + Nelson Rules 8가지
Cp / Cpk 공정능력 지수 계산
LiveCharts2 WPF 실시간 트렌드 차트
ASP.NET Core Web API + SignalR Push
추세 예측 (선형 회귀 → 임계값 도달 ETA)
대시보드 빌더 (Gauge / Table / Alarm 위젯)
④ CollectorRuntime
Windows Service · 읽기 전용
DAG 파이프라인 24시간 무인 수집
SDT 압축 알고리즘 (저장 95% 절감)
TagDataStore 메모리 현재값 + RingBuffer 이력
JSON 변경 감지 → 자동 Graceful 재시작
ParameterOnly 변경 → 핫 리로드 (무중단)
품질 등급 관리 (Good / Uncertain / Bad / Interpolated)
TPS / 에러율 1분 주기 통계 보고
⑤ AlarmEngine
Service + ASP.NET · alarm.json 쓰기
12종 상태 체크 룰 (임계/범위/기준값/변화율 등)

에스컬레이션 (H 5분 미확인 → HH 자동 격상)
Shelving — 유지보수 중 알람 일시 억제
이메일 / SMS / 카카오 알림톡 / Webhook / FCM
NotificationRouter — Severity × 수신자 × 야간 DND
알람 이력 DB + REST API (조회/ACK/Shelve)

③ 프로그램 명칭 추천
① 장비관리
NexField Studio
기존: DeviceManager
Next + Field(현장) + Studio(편집기). 현장 설비를 설계하는 작업실 이미지. "NexField"는 짧고 발음하기 쉬우며 산업용 소프트웨어 네이밍 톤에 잘 맞음.
② 수집설정
FlowForge
기존: CollectConfig
Flow(데이터 흐름) + Forge(주조·제작). NodeRed 방식으로 데이터 파이프라인을 '만들어낸다'는 뉘앙스. 직관적이고 개발자 친화적.
③ 모니터링
ScopeView
기존: Monitor
Scope(오실로스코프·범위) + View(시각화). 산업 계측기기 용어인 Scope를 활용, 데이터를 '관찰한다'는 의미를 직접 전달. 로컬+웹 양쪽 모두 어울림.
④ 수집런타임
DataPulse
기존: CollectorRuntime
Data + Pulse(맥박). 24시간 멈추지 않고 데이터를 '뛰게 한다'는 뜻. 백그라운드 서비스의 지속성과 실시간성을 함께 표현.
⑤ 알람엔진
AlertCore
기존: AlarmEngine
Alert(경보) + Core(핵심 엔진). 단순 알람 발송을 넘어 상태 판정·에스컬레이션·라우팅까지 담당하는 '핵심부'임을 강조. 전문적이고 간결.
⑥ 총괄관리
Nexus Hub
기존: Manager
Nexus(연결점·중심) + Hub(허브). 모든 프로그램을 연결하고 총괄하는 중심 거점 이미지. 전체 시스템의 관제탑 역할을 직관적으로 표현.
④ 제품 패밀리 네임 추천
NexPulse Suite
Next(미래) + Pulse(실시간 맥박). 6개 프로그램을 하나의 산업용 IIoT 플랫폼으로 묶는 브랜드.
FieldCore Platform
Field(현장) + Core(핵심). 현장 데이터를 핵심적으로 수집·관리한다는 의미. 산업 고객에게 신뢰감을 줌.
DataStream Pro
단순하고 직관적. 데이터가 흐른다는 개념 전달. "Pro" 붙여 전문 산업용 솔루션임을 강조.
