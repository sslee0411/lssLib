  1. SignalR 란?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  ASP.NET Core 에 내장된 실시간 양방향 통신 라이브러리.
  HTTP 폴링이 아닌 WebSocket 을 기반으로 서버 → 클라이언트 Push 를 지원.

  [MQTT vs SignalR 차이]
  ┌────────────────┬────────────────────────┬────────────────────────────┐
  │ 항목           │ MQTT (C-10)            │ SignalR (C-11)             │
  ├────────────────┼────────────────────────┼────────────────────────────┤
  │ 중간 서버      │ 브로커 필요             │ 없음 (Collector 자체가 서버) │
  │ 주 수신자      │ WPF Monitor, 외부시스템 │ 웹 브라우저, 모바일 앱      │
  │ 프로토콜       │ MQTT 3.1.1 (TCP)        │ WebSocket / HTTP           │
  │ 클라이언트언어 │ 모든 언어               │ JS/TS, C#, Java, Python    │
  │ 인터넷 연결    │ 브로커만 공개           │ Collector 포트 공개 필요   │
  └────────────────┴────────────────────────┴────────────────────────────┘

  [IIoT 에서의 역할]
  - 웹 브라우저에서 실시간 수집값·알람을 조회
  - 별도 Monitor 앱이 없어도 즉시 현장 확인 가능
  - IIoT.Monitor WPF 에서도 동일한 Hub 에 C# 클라이언트로 연결 가능
  - 향후 모바일 앱(MAUI) 연결 지원

  4. 메시지 구조 (Push 페이로드)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  [TagValue — 수집값 갱신 이벤트]
  이벤트명: "TagValue"
  발생 시점: FlowEngine 폴링마다 (PollMs 주기)

  {
    "tagId":    "T001",               // Tag 고유 ID
    "plcId":    "PLC-01",             // PLC/Device ID
    "rawValue": 1234.5,               // 드라이버 원시값
    "engValue": 12.3,                 // ScaleEngine 변환값 (공학단위)
    "unit":     "bar",                // 공학 단위
    "quality":  "Good",               // 품질: Good / Bad / Timeout / Disconnected
    "ts":       "2026-07-01T12:00:00.000Z"  // 수집 타임스탬프 (UTC ISO8601)
  }

  [AlarmChanged — 알람 상태 변경 이벤트]
  이벤트명: "AlarmChanged"
  발생 시점: 알람 발생(Active) / ACK / 복귀(Recovered) 시

  {
    "alarmKey": "T001:HH",            // 알람 고유 키 (TagId:Level)
    "tagId":    "T001",               // Tag ID
    "tagName":  "압력 센서 1",         // Tag 표시 이름
    "plcId":    "PLC-01",             // PLC ID
    "level":    "HH",                 // 레벨: HH / H / L / LL
    "status":   "Active",             // 상태: Active / Acked / Recovered
    "message":  "압력 위험",           // 알람 메시지
    "engValue": 95.2,                 // 발생 시 공학값
    "ts":       "2026-07-01T12:00:01.000Z"  // 발생 시각 (UTC ISO8601)
  }

  5. settings.json 설정
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  경로: {Collector 실행파일}\Config\settings.json
  (최초 실행 시 기본값으로 자동 생성)

  {
    "SignalR": {
      "Enabled": true,               // false = 서버 미시작 (수집에 영향 없음)
      "Port": 7878,                  // 수신 포트 (기본: 7878)
      "AllowedOrigins": []           // CORS 허용 Origin 목록
                                     // 빈 배열 = 전체 허용 (개발용)
                                     // 운영: ["http://192.168.0.100:3000"]
    }
  }

  [항목별 설명]
  ┌────────────────┬──────────┬────────────────────────────────────────────┐
  │ 항목           │ 기본값   │ 설명                                       │
  ├────────────────┼──────────┼────────────────────────────────────────────┤
  │ Enabled        │ true     │ false 시 서버 비활성화. 수집은 계속 동작.   │
  │ Port           │ 7878     │ TCP 수신 포트. 방화벽 인바운드 허용 필요.   │
  │ AllowedOrigins │ []       │ CORS 제어. 빈 배열=전체허용(개발 중 권장). │
  └────────────────┴──────────┴────────────────────────────────────────────┘

  [운영 환경 설정 예시]
  {
    "SignalR": {
      "Enabled": true,
      "Port": 7878,
      "AllowedOrigins": [
        "http://192.168.0.100:3000",
        "http://dashboard.company.com"
      ]
    }
  }

  6. 브라우저 클라이언트 사용법 (JavaScript)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  [내장 대시보드 — 추가 작업 없이 바로 사용]
  1. Collector 실행
  2. 브라우저에서 http://localhost:7878 접속
  3. 실시간 Tag 값 및 알람 자동 표시


  [직접 구현 — HTML + JavaScript]

  <!-- 1. SignalR JS 라이브러리 포함 -->
  <script src="https://cdnjs.cloudflare.com/ajax/libs/microsoft-signalr/7.0.5/signalr.min.js"></script>

  <script>
  // 2. 연결 객체 생성
  const conn = new signalR.HubConnectionBuilder()
      .withUrl("http://localhost:7878/iiot")   // Hub URL
      .withAutomaticReconnect([1000, 3000, 5000, 10000])  // 재연결 간격(ms)
      .build();

  // 3. Tag 값 수신 핸들러 등록
  //    이벤트명 "TagValue" = 서버 SendAsync("TagValue", ...) 와 반드시 일치
  conn.on("TagValue", (data) => {
      console.log(`${data.tagId}: ${data.engValue} ${data.unit}`);
      // data.tagId / data.plcId / data.rawValue / data.engValue
      // data.unit / data.quality / data.ts
  });

  // 4. 알람 이벤트 수신 핸들러 등록
  conn.on("AlarmChanged", (data) => {
      console.log(`[${data.level}] ${data.tagName}: ${data.message}`);
      // data.alarmKey / data.level / data.status / data.message
      // data.engValue / data.ts
  });

  // 5. 연결 상태 이벤트
  conn.onreconnecting(() => console.log("재연결 중..."));
  conn.onreconnected(() => console.log("재연결 완료"));
  conn.onclose(() => console.log("연결 종료"));

  // 6. 연결 시작
  async function start() {
      try {
          await conn.start();
          console.log("SignalR 연결 완료");
      } catch (e) {
          console.error("연결 실패:", e);
          setTimeout(start, 3000);  // 3초 후 재시도
      }
  }
  start();
  </script>

  7. C# 클라이언트 사용법 (IIoT.Monitor / WPF)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  [패키지 설치]
  IIoT.Monitor.csproj 에 추가:

  [C# 연결 코드]

  using Microsoft.AspNetCore.SignalR.Client;
  using System.Text.Json;

  // 1. 연결 객체 생성
  var conn = new HubConnectionBuilder()
      .WithUrl("http://localhost:7878/iiot")
      .WithAutomaticReconnect(new[] {
          TimeSpan.FromSeconds(1),
          TimeSpan.FromSeconds(3),
          TimeSpan.FromSeconds(5)
      })
      .Build();

  // 2. Tag 값 수신
  conn.On<JsonElement>("TagValue", (data) =>
  {
      var tagId    = data.GetProperty("tagId").GetString();
      var engValue = data.GetProperty("engValue").GetDouble();
      var unit     = data.GetProperty("unit").GetString();
      var quality  = data.GetProperty("quality").GetString();
      var ts       = data.GetProperty("ts").GetString();

      // UI 갱신은 반드시 Dispatcher 사용
      Application.Current.Dispatcher.InvokeAsync(() =>
      {
          // LiveTagViewModel 갱신 등
      });
  });

  // 3. 알람 이벤트 수신
  conn.On<JsonElement>("AlarmChanged", (data) =>
  {
      var level   = data.GetProperty("level").GetString();   // HH/H/L/LL
      var status  = data.GetProperty("status").GetString();  // Active/Acked/Recovered
      var message = data.GetProperty("message").GetString();
      var tagName = data.GetProperty("tagName").GetString();
  });

  // 4. 연결 상태 이벤트
  conn.Reconnecting += (ex) => { /* 재연결 중 UI 갱신 */ return Task.CompletedTask; };
  conn.Reconnected  += (id) => { /* 재연결 완료 UI 갱신 */ return Task.CompletedTask; };
  conn.Closed       += (ex) => { /* 연결 종료 UI 갱신 */ return Task.CompletedTask; };

  // 5. 연결 시작
  await conn.StartAsync();

  // 6. 종료 시 정리
  await conn.StopAsync();
  await conn.DisposeAsync();

  8. 방화벽 설정 (원격 접속 시)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  같은 PC 내에서만 접속하면 방화벽 설정 불필요.
  다른 PC / 모바일에서 접속 시 아래 설정 필요.

  [방법 1 — PowerShell (관리자 권한)]
  netsh advfirewall firewall add rule ^
      name="IIoT Collector SignalR 7878" ^
      protocol=TCP ^
      dir=in ^
      localport=7878 ^
      action=allow

  [방법 2 — Windows 방화벽 GUI]
  제어판 → Windows Defender 방화벽
  → 고급 설정 → 인바운드 규칙 → 새 규칙
  → 포트 선택 → TCP → 특정 포트 7878
  → 연결 허용 → 이름: "IIoT Collector SignalR"

  [방법 3 — 방화벽 비활성화 (개발 환경 전용, 운영 비권장)]
  Windows Defender 방화벽 → Windows Defender 방화벽 끄기

  [원격 접속 주소]
  Collector 가 실행 중인 PC 의 IP 확인:
  cmd > ipconfig → IPv4 주소 확인 (예: 192.168.0.10)

  브라우저:       http://192.168.0.10:7878
  SignalR Hub:    ws://192.168.0.10:7878/iiot
  헬스체크:       http://192.168.0.10:7878/health

  10. 주요 오류 및 해결
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  [오류 1] FrameworkReference 미추가 오류 (빌드 시)
  현상: CS0246 'WebApplication' 형식을 찾을 수 없음
  원인: Microsoft.AspNetCore.App FrameworkReference 누락
  해결: IIoT.Collector.csproj 에 추가:
        <ItemGroup>
          <FrameworkReference Include="Microsoft.AspNetCore.App" />
        </ItemGroup>

  [오류 2] RunAsync / StopAsync 인수 오류
  현상: CancellationToken→string 변환 불가 / TimeSpan→CancellationToken 변환 불가
  원인: API 시그니처 혼동
  해결:
        // 잘못된 코드
        await _app.RunAsync(_cts.Token);              // RunAsync 는 string? url 인수
        await _app.StopAsync(TimeSpan.FromSeconds(3)); // StopAsync 는 CancellationToken

        // 올바른 코드
        _app.Run();                                    // 블로킹 실행 (별도 스레드에서)
        using var cts = new CancellationTokenSource(TimeSpan.FromSeconds(3));
        await _app.StopAsync(cts.Token);

  [오류 3] CORS 오류 (브라우저 콘솔)
  현상: Access to ... has been blocked by CORS policy
  원인: AllowedOrigins 설정 불일치
  해결: settings.json AllowedOrigins 에 클라이언트 Origin 추가
        또는 빈 배열 유지 (개발 중 전체 허용)

  [오류 4] 포트 이미 사용 중
  현상: Address already in use. 7878
  원인: 다른 프로세스가 이미 7878 포트 점유
  해결:
        // 사용 중인 프로세스 확인
        netstat -ano | findstr :7878
        // PID 확인 후 종료 또는 settings.json Port 변경

  [오류 5] 연결 후 메시지 수신 안 됨
  현상: conn.start() 성공하지만 "TagValue" 이벤트 미수신
  원인: SignalRPushService.Initialize() 미호출 또는
        EventBus 구독이 FlowEngine 시작 전에 이루어짐
  해결: App.xaml.cs 호출 순서 확인:
        FlowEngine.StartAsync() → SignalRPushService.Initialize()

  [오류 6] index.html 404
  현상: http://localhost:7878 접속 시 404 Not Found
  원인: wwwroot 폴더가 빌드 출력에 복사되지 않음
  해결: IIoT.Collector.csproj 에 추가:
        <ItemGroup>
          <Content Include="wwwroot\**\*">
            <CopyToOutputDirectory>PreserveNewest</CopyToOutputDirectory>
          </Content>
        </ItemGroup>
